# Project Statement 4: Restaurant Website

## Project Objective

The objective of this project is to enable students to design a restaurant website using HTML and CSS Flexbox for layout and alignment.

---

## Project Information

| Field | Details |
|---|---|
| **Project Title** | Restaurant Website |
| **Dataset Source** | Self-Created Content |
| **Difficulty Level** | Beginner |
| **Primary Skills** | HTML, CSS Flexbox, Git |

### Problem Description

Create a restaurant website that includes menu, about section, gallery, and contact details with proper layout using Flexbox.

---

## Required Steps

1. Create HTML structure
2. Add header and navigation
3. Create menu section
4. Use Flexbox for layout
5. Add images for dishes
6. Style using CSS
7. Improve spacing and alignment
8. Add footer
9. Make responsive
10. Push to Git
